## Повторение

Python 3.12.10. Из этого каталога:

```sh
python -m pip install -r requirements.txt
python download_data.py
python pipeline.py train
```

Обучение автоматически извлекает CSV, проверяет число строк, выделяет первые
910168 строк, дважды вычисляет причинные признаки, запускает все эксперименты,
сохраняет модель, разметку и тест. Загрузка архива нужна только при отсутствии
data/metropt.zip. SHA-256 исходного CSV указан в results/summary.json.
Данные относятся к 2020 году; дата выполнения работы — 2026 год.

Подготовка отдельной порции:

```sh
python pipeline.py prepare --input data/batch_01.csv --context data/initial.csv --output results/batch_01_prepared.csv
```

Для первой порции context не нужен. Без прошлого контекста начало новой порции
будет проходить повторный прогрев. Файлы порций можно выделить из CSV по
границам manifest.json; вспомогательный verify.py делает это автоматически.

## Результаты

- results/experiments.csv — все конфигурации, параметры, AP, ROC-AUC, полнота и время fit.
- results/grid_*.csv — полный перебор параметров.
- results/model_v1.joblib — сохраненный sklearn Pipeline.
- results/summary.json — паспорт запуска, хеши, версии и границы.
- results/test_locked.csv — июньский тест, метрики по нему не вычислялись.
- results/coefficients.csv — коэффициенты L1 при C=0.1.
- results/verification.json — проверки причинности и порционного расчета.

Пять новых признаков: среднее TP3 за 30 минут, наклон TP3 за 10 минут,
доля и число переключений нагрузки за 30 минут, разность TP3 и Reservoirs.
Сетка 10 секунд, выдача раз в минуту. Полные правила указаны в отчете.

Из трех событий исходной части E1 используется для обучения, E2 — для настройки,
E3 отложено. Есть только одно допустимое событийное временное разбиение:
результат не является надежной оценкой по множеству независимых отказов.
Итоговое дерево имеет глубину 5 и минимум 60 строк в листе.
AP на настройке около 0.041, базовая AP около 0.035; полнота при 0.5 равна нулю.
Это исследовательский кандидат; практическая пригодность не подтверждена.
Порог и независимая оценка относятся к ПР4.
